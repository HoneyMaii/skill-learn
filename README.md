# skill-learn
这是一个专门用来记录和学习实际使用的、好用的SKILL仓库。

## 使用方式

### 1) 在仓库里记录自己创建的 SKILL

- 每个 SKILL 使用一个独立文档：`/skills/<skill-name>.md`
- 推荐统一结构：目标、适用场景、输入、步骤、示例、注意事项

已记录的 SKILL（持续补充）：

- `skills/skill-template.md`（模板）

### 2) 在 GitHub Wiki 为每个 SKILL 建立手册

如果你还不熟悉 GitHub Wiki，可以先看仓库内指南：

- `docs/github-wiki-guide.md`

建议做法：

1. Wiki 的 `Home` 页面作为总目录；
2. 每个 SKILL 建一个独立页面（页面名与文件名保持一致）；
3. 每个页面按统一模板填写，方便后续维护。
